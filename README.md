# 东方财富条件选股结果

这是一个纯静态的单页股票筛选页面，用来展示东方财富条件选股返回的数据，并按表格方式做分组和汇总展示。

## 功能

- 直接读取东方财富数据
- 展示最新价、市盈率、市净率、总市值等基础指标
- 展示净资产收益率、毛利率、净利率等财务指标
- 展示合同负债及其同比、环比增长数据
- 表头按时间和指标分层显示，便于横向对比
- 页面可直接部署到 GitHub Pages

## 使用方式

1. 将仓库根目录的 `index.html` 作为入口文件
2. 用浏览器直接打开，或放到静态站点环境中访问
3. 页面会在浏览器中直接请求东方财富接口并渲染数据

## 部署到 GitHub Pages

这个项目不依赖后端服务，适合直接发布为静态站点：

1. 把 `index.html` 推到 GitHub 仓库根目录
2. 在 GitHub 仓库设置里打开 Pages
3. 选择 `main` 分支和根目录作为发布源
4. 保存后等待 GitHub Pages 生成链接

## 说明

- 当前版本以浏览器直连东方财富数据为主
- 没有本地快照兜底逻辑
- 适合做公开演示、个人看盘页、静态部署
